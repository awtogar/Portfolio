**Section label:**
```
Process
```

**Section intro:**
```
Every project follows the same discipline —
understand first, design second, build third.
```

**Step 01:**
```
(01)
Discover

I start by asking the right questions. Goals, audience, constraints — understanding the problem clearly before jumping to solutions.
```

**Step 02:**
```
(02)
Define

Clarity before creativity. I translate what I've learned into a direction — structure, flow, and design intent that keeps decisions grounded.
```

**Step 03:**
```
(03)
Design

Visual decisions made with purpose. I move into high fidelity early because I think better when things look real.
```

**Step 03:**
```
(04)
Build

I write the code myself. Design and development in one person means fewer gaps, faster iteration, and output that matches the intent.
```
